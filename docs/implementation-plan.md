# 诊断版本实施计划（2026-11-11）

用户已授权按聊天中确认的诊断方案实施并上传仓库。

1. 保留原有算法与选模，添加共享诊断记录器。先测试排名并列、逐试次关联、纠错/破坏恒等式。
2. 两条自适应流水线接入记录器，保存全部候选的 Evidence；并行任务独立目录避免竞争。
3. 三个入口提供可配置输入和输出；记录运行配置。原数据和旧结果不覆盖、不上传。
4. 添加文档、依赖、自动化测试、贡献规范与后续路线。
5. 验证语法、单元测试、合成数据端到端测试及旧版预测一致性，然后上传并核对。

审查重点：外层标签仅用于诊断评分；排名仍用内层 MI 准确率；并列遵循原字典顺序；记录不能改变概率；输出隔离且能关联到原试次。
